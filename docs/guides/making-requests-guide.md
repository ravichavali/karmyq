# Asking for Help

Posting a request is how you ask your community for help.

---

## How to Post a Request

1. From your dashboard or the community feed, click **New Request**
2. Choose a request type (see below)
3. Write a clear title and description
4. Set a location if relevant
5. Set an expiration
6. Submit

Your request will appear in the community feed.

---

## Request Types

- **General Help 🤝** — Anything that doesn't fit a specific category
- **Ride 🚗** — You need a ride somewhere; include pickup and dropoff locations
- **Service 🔧** — You need a skill: repairs, tutoring, tech help
- **Event 📅** — You're organizing something and need help or volunteers
- **Borrow 📦** — You need to borrow something; specify what and for how long

Your community may also have custom request types created by the founder.

---

## Writing a Good Request

**Be specific.** "Help with moving" is vague. "Help carry boxes from a 2nd-floor apartment to a moving van on Saturday morning — about 2 hours" is something someone can say yes or no to.

**Be honest about effort.** If something will take three hours, say three hours.

**Set a realistic expiration.** If you need help this weekend, set the expiration before then.

---

## What Happens After

1. Your request appears in the feed
2. Members express interest or accept your request
3. You receive a notification
4. You message them to coordinate details
5. Once complete, you mark it as fulfilled
6. Karma transfers from your balance to the helper's

---

## Tips

- Post earlier than you think you need to
- A clear, friendly title gets more attention
- If time-sensitive, say so in the description
