# Gemini Architecture Review

This directory contains architecture designs, roadmaps, and decision records created by **Gemini (Antigravity)** to guide the evolution of the Karmyq platform.

## Artifacts

- **[architecture_review.md](./architecture_review.md)**: The initial comprehensive review of the Karmyq platform.
- **[roadmap.md](./roadmap.md)**: The high-level vision and phases for the "Everything App" transition.
- **[foundation_snippets.md](./foundation_snippets.md)**: Ready-to-use SQL migrations and Zod schemas for the initial database changes.
- **[gateway_design.md](./gateway_design.md)**: Architecture spec for the new Node.js API Gateway (Dynamic UI & Auth).
- **[events_architecture.md](./events_architecture.md)**: Architecture spec for the Redis/BullMQ Event Bus.

## Usage

These documents are intended to provide context and specifications for implementation. You can reference them when asking Claude or other assistants to write code.
